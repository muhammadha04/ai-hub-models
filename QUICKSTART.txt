================================================================================
        COMBINED SEGMENTATION + DEPTH DETECTION - QUICK START
================================================================================

You now have a complete system to run quantized segmentation + depth models!

MODELS USED:
├── YOLOv11-Segmentation (w8a16 quantized)
│   └── Best-in-class object segmentation
│   └── 80 COCO classes, 640x640 input
│   └── ~20-30ms inference on Snapdragon 8 Gen 3
│
└── Depth-Anything-V2 (int8 quantized)
    └── State-of-the-art depth estimation
    └── 518x518 input, dense depth output
    └── ~100-150ms inference on Snapdragon 8 Gen 3

WHAT YOU GET:
✓ Object detection with segmentation masks
✓ Per-pixel depth estimation
✓ Depth statistics for each detected object
✓ Combined visualization
✓ Export scripts for on-device deployment

================================================================================
                            INSTALLATION
================================================================================

1. Install required packages:
   
   pip install "qai-hub-models[yolov11-seg,depth-anything-v2]" matplotlib

2. (Optional) For on-device export, configure AI Hub:
   
   pip install qai-hub
   qai-hub configure --api_token YOUR_TOKEN
   
   Get token from: https://app.aihub.qualcomm.com/account/

================================================================================
                            QUICK RUN
================================================================================

# Run demo with default test image
python3 combined_segmentation_depth_demo.py

# Run with your own image
python3 combined_segmentation_depth_demo.py --image photo.jpg --output result.png

# Test your environment
python3 test_combined_models.py

# See export options for on-device deployment
python3 combined_segmentation_depth_export.py --help

================================================================================
                        EXAMPLE OUTPUT
================================================================================

The demo creates a 2x2 visualization:
┌─────────────────────┬─────────────────────┐
│  Original Image     │  Segmentation       │
│                     │  (colored masks)    │
├─────────────────────┼─────────────────────┤
│  Depth Heatmap      │  Combined:          │
│  (plasma colormap)  │  Seg + Depth Stats  │
└─────────────────────┴─────────────────────┘

Each detected object gets:
  - Bounding box
  - Segmentation mask
  - Class label & confidence
  - Average depth measurement

================================================================================
                        PERFORMANCE NOTES
================================================================================

YOLOv11-Segmentation:
  CPU (laptop):    ~100-200ms
  Snapdragon 8G3:  ~20-30ms (NPU)
  Model size:      11.4 MB (quantized)

Depth-Anything-V2:
  CPU (laptop):    ~500-800ms
  Snapdragon 8G3:  ~100-150ms (NPU)
  Model size:      ~25 MB (quantized)

Combined pipeline can run models in parallel on separate cores for best performance.
